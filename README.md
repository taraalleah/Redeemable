# Redeemable ˗ˏˋ ꒰ ✉︎ ꒱ ˎˊ-

*Little tickets, sealed with care.*

Redeemable lets you make a handful of cute, customizable tickets, like **1 breakfast in bed**, **1 free favour** or **1 very long hug**, tuck them in an envelope, and send them to your loved ones.

## How it works

**Sending**
1. Open the envelope (or tap *Make custom tickets*).
2. Add who it's for and who it's from.
3. Make up to 8 tickets. Pick a template or write your own, then choose a colour and a shape.
4. Tap *Seal the envelope* and copy your link.

**Receiving**
1. Open the link and tap the envelope.
2. The tickets pop out. Save any of them as an image.
3. Tap *Make tickets to give back* to send some in return.

## A little note on privacy

There are no accounts and no database. Your tickets are packed into the link itself, so anyone who has the link can open the envelope. Share it only with people you want to see it.

## Run it yourself

```
npm install
npm run dev
```

Build for hosting with `npm run build`. It deploys to GitHub Pages automatically (Settings > Pages > Source: GitHub Actions).

## Made with

Vite, React, a canvas for the tickets, and a lot of paper-and-typewriter feelings. Fonts: Special Elite and Courier Prime.
